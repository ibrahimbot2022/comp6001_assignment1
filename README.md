## Project Overview
This project investigates the effect of motion blur on object detection and evaluates whether image restoration (deblurring) improves detection performance.

The project includes:
- Image deblurring
- Object detection on blurred and restored images
- Dataset preparation and training
- Performance evaluation and comparison
